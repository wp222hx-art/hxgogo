# 统一研究工作台

桌面默认打开 /workspace，依次提供总览、生成方案、策略追踪、数据管理。统一导航保留图谱、量化、AI、实验室、逐期查询、精选、配置及演示。在线来源选择跨页面保留，图谱的本地导入来源仍独立管理。

## 一次完整使用

1. 数据管理选择来源，查看最新期号、同步状态和快照质量。
2. 生成方案选择固定配方与 100 / 150 / 300 / 500 个号码，点击“生成并锁定本期方案”。
3. 详情可复制、导出、关注、备注。相同期次与配置重复点击返回首次锁定结果。
4. 策略追踪按来源、配方版本与覆盖数量分别核对，开奖数据更正或删除会反映到当前核对结果。

本地配方无须 AI 密钥。“均衡观察”和“集中观察”复用原量化排序引擎；“随机对照”使用期号固定种子洗牌。前三位固定为万、千、百，保留前导零。覆盖数量增加本身会提高理论覆盖率，不构成预测优势。

## 统计口径

- 理论覆盖：去重号码数 / 1000，仅适用于前三位独立均匀假设。
- 历史实测：已核对命中数 / 已核对期数。每个固定配置最近 500 份开奖前锁定记录，等待数据与无效结果不算未命中。
- 区间：95% Wilson 描述性区间。连续观察、多策略选择与期次相关性会影响解释，不能直接推成下一期概率。
- 最多连续未中：按连续真实期号统计，缺期或缺失结果中断。
- 下期已校准概率：null，界面显示“尚无”。模型评分未经过独立概率校准，不作为命中承诺。
- 原量化 / AI 的可验证 live 记录一并展示，旧记录与历史回放不进入实测榜。关注和备注不影响样本范围。

方法参考：[NIST 的二项比例区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)、[scikit-learn 概率校准说明](https://scikit-learn.org/stable/modules/calibration.html)。

## 共用数据与 API

契约为 studio.v1，来源由现有五个在线来源目录校验。

- GET /api/studio/overview?source=...：共用快照、生成门槛、配方、最近 100 份方案与固定配置统计。读取不触发同步或 AI；跨查询检查开奖版本，变化时重读，持续变化时返回 409。
- POST /api/studio/plans：source、recipe、count、expect、revision。至少最近 120 期连续有效数据；截止前锁定。数据库触发器再次验证截止、目标未开奖、数据版本与号码有效性。
- PATCH /api/studio/plans/:id：note、pinned，仅修改独立备注表。
- GET /api/studio/data?source=...&period=...&limit=...：原始开奖记录，限制 1–3000 期；界面当前查询默认最近 100 期，可导出 CSV。
- 同步继续使用 /api/atlas/sync，图谱、分析与工作台共用 draws 和持久版本；没有复制第二份开奖库。

studio_plans 保存首次号码、配方版本、输入期号、版本、样本数量和截止时间，禁止更新或删除。studio_annotations 单独保存关注及备注。核对结果读取时关联 canonical draws，不缓存陈旧命中标记。方案记录可证明保存的号码与当时输入版本，未保存完整历史输入副本，不等同于永久保留可重放的上游原始数据。

未来接入其他 API 时，应先完成来源目录、期号日历、字段验证、来源标记与原子入库，再接入同一快照契约。大乐透、11选5等不同样本空间不可套用前三位的 1000 分母。
