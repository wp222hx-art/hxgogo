# 独立研究工作台使用说明

入口为 `/atlas`，与原平台的数据分析、预测留档和 AI 配置并行。顶部先选择数据来源、号码投影和分区，随后配置条件、查看候选与历史分布。每个工具都标明当前来源和样本范围。

## 玩法与条件口径

- 三位数字保留位置且允许重复；五位来源可选择前、中、后三位或完整五位，不能把不同投影混为同一方案。
- 11选5“任2/任3/任4/任5”的每期记录仍是完整五个开奖数。条件逐个检查当期的 N 码子集，任一子集满足即为该期匹配；每期最多计一次。“前2/前3”按原始开奖位置截取并保留顺序。
- 大乐透前区和后区分别计算。前区是 1–35 选 5，后区是 1–12 选 2。工具的热号、遗漏和胆拖都只针对当前区。
- 条件允许值、公式、每条容错与全局容错在条件编辑器明示。AC、间空、边邻、跳位等名称不能单凭参考截图断定原软件的内部公式，本平台采用目录中明确列出的版本。
- 参数按“来源 + 投影 + 分区”分别保存。跳位配对编辑器使用从 1 开始的位置，例如 `1-3,2-4`；留空会恢复默认隔位配对，两位玩法使用相邻位置。无序组合先升序排列。是否将 1 归入业务“质”组可手动设置，这不改变 1 不是数学质数的事实。

## 双方案监测

支持两套独立方案。可以使用当前条件、粘贴每行一组的明确号码，或载入已保存方案；再设置提醒阈值并开始。

开始时将当前最后一期设为观察起点，旧记录不进入新日志。页面每 15 秒刷新一次，只有本页打开时进行自动观察与提醒。停止、重启和恢复工作区不会自动补写中间的记录。离开页签后刷新计时器停止。

提醒阈值指新到达记录的连续未匹配次数。已知缺期、无法计算的跨期指标、上次起点掉出当前窗口时均中断连续段。无法计算显示“未知”，不会被当成未命中。本地来源没有确定期历时，“前一期”仅表示导入时间序列中的相邻记录。

迟到数据和新导入历史也可能成为新到达记录，因此这些日志是本机观察记录，不是开奖前预测成绩。保存、复制和提交条件时保留方案的来源、玩法、容错、反集与指标参数；来源或范围不一致时须切换或重新载入。明确号码方案最多 2000 组；更大的候选应保存条件规则。

## 遗漏与组合

提供当前玩法全集、当前条件候选、2–10 码组合三种范围。全集或待分析组合超过 10000 组时要求缩小范围，避免把前几页误称为全集。表格显示前 300 行，起止序号操作针对完整已计算排序，可复制、保存或送入监测，每次最多 2000 组。

组合事件明确定义：组合大小小于当期完整开奖数量时，组合内每个号码都必须出现在开奖中；组合大小大于或等于开奖数量时，当期全部号码都必须包含在组合中。这样 6–10 码组合仍有可计算含义。组合事件方案用于监测和历史 K 线，不能直接当作一注精确号码加载。

当前遗漏是末尾已知连续段的未匹配长度，最大遗漏是窗口内最长已知未匹配段。已知缺期中断连续段；从未出现的事件只能给出已观察长度的下界，显示“≥”。遗漏久不意味着下一次必然更容易发生。

## 历史命中 K 线

选择当前条件或已保存方案。每个已知匹配加 1，已知未匹配减 1，按指定样本数聚合出开、高、低、收。未知值不增减累计值，并中断聚合与连续统计。匹配率的分母只包含可计算样本。

图上指标不是金融价格、资金曲线或盈利统计。看过历史再挑选方案属于历史回看，不能据此宣称具有预测优势。可以导出带 `historical_match_not_forecast` 类型的逐期结果，保留未知与缺期标记。

## 胆拖与热胆

用于无序且号码不重复的玩法。输入固定胆码与互不重合的拖码，从拖码中补足当前任选数量。支持 1拖6、1拖7、1拖8 的格式示例；示例仅按号码从小到大填入，不是推荐。

历史匹配事件是：当期号码中存在一组符合当前任选数量的组合，包含全部胆码，其余号码来自拖码。每期最多计一次。生成号码可以复制、保存、提交到条件或画历史 K 线。号码出现排行按每期去重后统计，热号只是样本事实。

## 本地知识助手与成本计算

知识助手提供四个快捷问题，并可查询指标目录。样本摘要直接从当前记录计算，不调用真实 AI，也不会读取或使用 API 密钥。现有 AI 配置中心保留独立链接。

成本计算只根据注数、单位金额、期数和人工输入倍数做算术，显示当期成本、累计成本与预算余额。不根据遗漏或置信度推荐加倍，不计算未提供的奖金或宣称盈利。

## 足球工作区

足球入口提供胜平负、让球、半全场、总进球、比分、混合、传统、情报、遗漏、K线和直播视图。只展示本地足球来源实际导入的赛事。

终场胜平负、比分和总进球可由有效的已完赛比分计算。当前导入契约不含赔率、让球值、半场比分、伤停资料或传统14场/任选9场期次；这些内容显示缺失，不编造结果。直播视图仅呈现已导入的未开赛或进行中状态，不含网络比分源与视频。遗漏和 K 线只使用有明确开赛时间的已完赛记录；不同赛事不是同分布随机试验。

## 数据导入与工作区备份

“数据与格式”可设置号码分隔符、两位补零、指标参数，导出当前数据与工作区 JSON，或恢复工作区。恢复前需勾选替换确认；恢复后的监测一律停止。工作区仅存本板块内容，不覆盖旧平台预测成绩。

导入入口：`POST /api/atlas/import`。仅接受 `local:digits3`、`local:eleven5`、`local:dlt`、`local:football`。请求为 `{ "sourceId": "...", "records": [...] }`，每批最多 3000 条、4 MiB。数据按唯一期号或比赛 ID 追加留档，重复键不能覆盖已有记录；先检查样例再导入。时间用毫秒时间戳或带时区的 ISO 字符串。

三位数字示例：

```json
{"sourceId":"local:digits3","records":[{"period":"example-001","numbers":[1,2,3],"drawAt":"2026-09-01T12:00:00+08:00"}]}
```

11选5使用原始五位开奖顺序，例如 `"numbers":[1,3,5,7,11]`。大乐透使用分区：

```json
{"sourceId":"local:dlt","records":[{"period":"example-001","zones":{"front":[1,7,15,21,35],"back":[2,12]},"drawAt":"2026-09-01T12:00:00+08:00"}]}
```

足球示例：

```json
{"sourceId":"local:football","records":[{"matchId":"example-match-001","kickoff":"2026-09-01T20:00:00+08:00","home":"示例主队","away":"示例客队","status":"finished","homeScore":2,"awayScore":1}]}
```

`status` 为 `scheduled`、`live`、`finished`、`postponed` 或 `cancelled`；未提供的时间或比分按契约留空，不能用示例值假装真实资料。

共享工作区：`GET /api/atlas/workspace` 和 `PUT /api/atlas/workspace`。PUT 可提交 `{ "workspace": { "presets": [], "monitors": [], "preferences": {} } }`。总量上限 256 KiB；浏览器提前按约 250 KB 检查。方案保存来源、玩法、规则、参数及有界号码集，不保存无限枚举结果。接口沿用本地服务的鉴权与来源约束。
