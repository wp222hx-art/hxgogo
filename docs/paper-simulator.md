# 模拟机器人

入口：左侧“模拟机器人”，也可从策略追踪点击“模拟此策略”。原功能继续使用同一份开奖数据。

## 从策略到模拟

1. 选择来源、AI / 竞技场策略版本和覆盖数量。机器人支持 100、200、300、450、500 注；已有的可验证量化 / AI 方案也可使用。
2. 设置模拟本金、每个号码的金额、假设返还倍数和停止条件。
3. 先运行最近 60、120 或 300 期历史模拟，对照同策略平投的资金曲线。
4. 点击“启动前瞻模拟”。参数和所选策略固定后不能回写；需要调整时结束本轮并新建机器人。
5. 在账本中查看逐期投入、结果、余额与日志，也可导出完整 JSON。

全部使用模拟资金。机器人不连接投注账户，不调用支付接口。创建机器人也不会自动启用或调用付费 AI；原 AI 策略只能等待原后台已经生成的有效方案。

## 四种金额规则

| 模式 | 规则 |
|---|---|
| 平投 | 每期维持基础金额 |
| 连中加码 | 连续命中达到触发次数后加一档；继续命中继续加档，未命中后回到基础金额 |
| 连不中加码 | 连续未中达到触发次数后加一档；命中后回到基础金额 |
| 双向规则 | 分别响应已经观察到的连中和连不中，不把历史状态当作下一期机会预测 |

缺期会打断连续状态。手动暂停保留账本；恢复时从基础金额重新开始。待结算记录没有结果时不能恢复加码。关机、休眠或数据中断期间不补写过去的模拟投入。

默认参数只是演示：本金 10,000，单号金额 0.20，覆盖 500 个时基础每期总额 100；加码倍数 2、连续 2 次触发、最多 4 档、单期总额上限 2,000、净亏损上限 3,000、净盈利上限 3,000、最多 500 期、假设含本金返还倍数 950。可在启动前自行修改。

金额按分计算，加码后的单号金额向上取整到分，再乘覆盖数量。超过级数、单期金额、本金余额或期数上限时结束；如果下一期全损会超过净亏损上限，也不会继续。止损依据相对初始本金的净亏损；最大回撤依据历史资金峰值，两者不同。

## 计算口径

设覆盖数量为 N、单号金额为 u、假设含本金返还倍数为 R：

- 每期总投入 = N × u。
- 命中返还 = R × u；未中返还为 0。
- 净收益 = 返还 − 所有投入。
- 均匀独立的 000–999 空间下，理论覆盖率 = N / 1000。
- 假设收支平衡命中率 = N / R；每单位投入的理论期望收益率 = R / 1000 − 1。

例如覆盖 150 个、R = 950 时，理论覆盖率为 15%，收支平衡需要约 15.79%；覆盖 500 个时对应理论覆盖率为 50%，收支平衡需要约 52.63%。均匀独立假设下的期望收益率为 −5%。加码不会改变这套假设下的号码概率。

命中也不一定回本：覆盖 500 个，单号基础金额 1，每次未中翻倍，连续 5 次未中后第 6 次命中，含本金返还倍数 950，则总投入 31,500、返还 30,400，整段仍亏 1,100。此例是算术演示，不是推荐配置。

平投和加码各自执行停止条件，因此运行期数可能不同。不能直接把提前停止后的命中率差异理解成预测能力提升。

## 下期研究依据

页面按“此前基础状态 / 连中状态 / 连不中状态”展示后续命中次数、样本量和 Wilson 95% 描述性区间。平滑历史频率使用 20 个理论先验样本，减少小样本极端值。最后 30% 观察的 Brier 评分，每次只使用此前状态记录；越低越好，并与相同覆盖数量的理论基线比较。

历史配方重放对每一期仅使用之前的数据重算。由于策略和参数可能是在看过历史后选择的，它仍不是独立的未来验证。实际提前锁定的方案记录另有入口，不能与重放混为一谈。条件样本可能重叠，多策略筛选会产生选择偏差；页面保留“下期已校准概率：尚无”。

游程检查只描述最近连续样本段，命中和未中数量都超过 10 时显示近似 Z 值；它不能证明未来可预测。方法参考 [NIST 游程检验](https://www.itl.nist.gov/div898/handbook/eda/section3/eda35d.htm) 与 [NIST 比例区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)。

## 哈希研究

检查最近 1,000 条的哈希格式、重复、当前取号规则与实际号码的一致性，展示前三位数字频数和描述性卡方偏离度。这些检查没有验证链上最终性，也不构成上游公平认证。

安全哈希的单向性和不可轻易反推性质，不能转化成“通过过去尾数预测下一枚哈希”的能力；参见 [NIST 哈希定义](https://csrc.nist.gov/glossary/term/hash_function)。应优先研究取号偏差、数据完整性和固定规则在新增记录上的表现，而不是假设连中或连不中必然反转。

## 数据一致性与运行范围

机器人直接读取平台共用的开奖库、策略方案和来源版本，不建立另一份开奖真相。AI 主策略或竞技场 500 注记录作为本轮的选码底稿；100、200、300、450 注均按该底稿的前 N 注执行，所以 500 注数据和其他档位不会各自重新生成。若选择竞技场本来就独立生成的 100 / 200 / 300 / 450 注档位，页面会标明原始档位，并保留其独立来源。模拟投入保留原号码、时间、参数版本与数据版本；数据库拒绝重复期次、事后补写、过期版本和原始投入修改。

读取余额期间或保存投入之前发现开奖版本变化时，当前投入取消，等待下一轮处理。已结算开奖被更正或删除时，重新核对余额并暂停，复核后才能从基础金额恢复。未结算资金先从可用余额扣除，未知结果不计为未命中。

桌面后台运行时，按原有各来源同步节拍检查。关闭窗口到托盘可以继续；彻底退出、关机、休眠时不能运行。网页构建保留接口，但没有承诺云端常驻调度。

新增接口统一在 /api/paper，契约版本 paper.v1：catalog、replay、study、bots、控制与完整导出。每份记录保留来源、策略、版本、覆盖数量，为未来共享 API 的客户端和分析视图提供一致标识。最多同时保留 10 个运行或暂停机器人，每个最多 5,000 期；列表只显示最近 100 行，导出保留全量记录。
