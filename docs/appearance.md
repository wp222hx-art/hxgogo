# 外观与高亮

点击任意页面右上角的 **“◐ 主题名称”**，打开外观面板。选择卡片后立即生效，无需刷新；关闭面板、切换页面、重启应用都会保留本机偏好。

| 主题 | 展现方式 |
| --- | --- |
| 暖米白 | 奶油背景、杏棕选中，适合长时间阅读 |
| 股市经典 | 白底与蓝色选择，命中和正收益用红色，未中和负收益用绿色 |
| 绿金竞技 | 博彩平台风格，深绿面板、香槟金选择、绿色命中 |
| 赛博朋克 | 深紫背景、霓虹粉选择、冰青命中 |
| 游戏战术 | 靛蓝面板、紫色选择、青柠命中 |
| 科技金融 | 冰蓝留白、钴蓝选择、深青命中 |
| 加密交易所 | 石墨底色、明黄选择、红绿收益 |

**增强选择与命中高亮**会加粗边框；深色主题提供静态光晕。关闭后保留状态颜色与文字。不会闪烁。

- 选中：有色边框，代表当前选择或筛选。
- 命中、未中、待开奖：用文字徽标区分。
- 正负收益：保留正负号，并随主题使用相应颜色。
- 外观面板里的金额与号码只是配色示例，不是实际战绩。
- 图表坐标、文字、提示框与机器人收益曲线随主题变化。既有多策略曲线保留系列颜色，K 线保留原先红涨绿跌的标识。
- 主题切换保留正在编辑的金额和策略、图表缩放、已经锁定的号码及账本，不触发重新选码。
