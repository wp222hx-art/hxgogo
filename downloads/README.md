# HashPlay 下载

[**下载最新版（Windows x64）**](https://github.com/wp222hx-art/hxgogo/releases/latest) · [全部历史版本](https://github.com/wp222hx-art/hxgogo/releases)

每个版本提供便携版、安装版、SHA256SUMS.txt 校验文件和 release-manifest.json 版本清单。

- **便携版**：下载后直接运行。

升级前，从旧版系统托盘选择“退出并停止后台”，再启动新版。默认继续使用原数据库和配置，可先通过“数据 → 备份数据”备份。当前应用采用手动下载安装更新。
