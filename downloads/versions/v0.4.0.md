# HashPlay v0.4.0 · 统一研究工作台

## 更新内容

- 新首页串联总览、生成方案、策略追踪与数据管理；统一导航、数据来源与深色界面风格。
- 图谱、量化、AI、实验室、逐期查询和配置等原有功能继续保留。
- 本地固定配方一键生成并锁定，支持 100、150、300、500 个前三位号码，无需 AI 密钥。
- 校验最新期次、最近 120 期连续有效数据和截止时间；数据变化时拒绝保存过期方案。
- 方案首次结果不可改写，支持复制、导出、关注和复盘备注。
- 工作台与原量化 / AI 可验证记录共同展示，按策略版本和覆盖数量独立核对。
- 分开展示理论覆盖、历史命中率、95% 历史区间、基线差值和连续未中；下期已校准概率明确显示尚无。
- 数据管理集中展示五个来源的同步、最新期号、版本和查询导出；开奖结果更正后追踪重新核对。

## 验证

101 项自动测试通过；网页与桌面构建通过。Windows 桌面九个页面、新工作台生成至核对流程、原图谱流程、备注、导出、窄窗口、备份恢复与托盘检查通过。测试使用独立目录和合成记录，未使用真实付费 AI 密钥。这里的验证证明软件行为，不代表已经验证策略预测优势。

## 升级

下载 Windows x64 便携版或安装版。从旧版系统托盘选择“退出并停止后台”后启动新版，继续使用原数据库与配置，自动新增方案记录表。可先通过“数据 → 备份数据”备份。

所有在线分析仍共用原始开奖库。11选5、大乐透、足球保持本地导入入口。当前仍采用手动下载更新，未增加应用内自动安装。
