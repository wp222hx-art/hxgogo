# HashPlay v0.5.0 · 辅助模拟机器人

## 更新内容

- 新增独立“模拟机器人”板块，从策略追踪一键带入所选策略；原图谱、工作台、AI 与量化功能保留。
- 支持 100、200、300、450、500 注，单号金额 0.01–10 元；500 注底稿按前 N 注保持一致，并支持平投、连中加码、连不中加码、双向规则。
- 提供同策略平投对照、资金曲线、逐期账本、最大回撤、停止原因与完整导出。
- 本机后台可持续记录创建后的模拟投入，支持暂停、复核恢复和结束；关机期间不补写历史。
- 方案与资金规则固定，数据更正后重新核算并暂停；开奖版本、截止时间、账本序号共同阻止过期或重复投入。
- 增加条件历史频率、样本区间、后段评分、游程和哈希取号检查；下期已校准概率保持“尚无”。
- 本模块不连接投注账户，不自动启用付费 AI；所有资金及返还倍数都是模拟假设。

## 分析结论

五个来源各取 300 期、固定覆盖 150 个号码的历史重放中，均衡观察命中 218 / 1,500，随机对照 227 / 1,500；各来源可能相关，不能视作 1,500 个独立证据。尚无稳定提高下期命中率的依据。完整范围、采集状态与加码结果见 docs/paper-observations-2026-09-07.md。

倍投改变资金路径，不会自动提高命中率；触及资金或级数上限时结束，即使命中也可能无法覆盖前面的损失。

## 验证与升级

106 项自动测试通过，涵盖资金计算、停止边界、不可回写、并发与开奖更正；网页和桌面构建通过。Windows 十个页面、模拟创建至导出、暂停恢复、窄窗口、原工作台与图谱、备份和重启检查通过。界面测试使用独立合成数据，不能证明策略预测优势。

升级前从旧版托盘退出，可先备份数据库。新版自动新增模拟账本表；应用仍采用手动下载安装更新。使用方法见 docs/paper-simulator.md。
