# HashPlay v0.3.1 · 图谱与共享数据同步

## 更新内容

- 独立图谱工作台：条件筛选、排列、趋势、遗漏、方案监测、K 线、胆拖与数据格式工具。
- 图谱与原平台五个在线来源共用数据库，每 5 秒核对持久版本。
- 新增、历史更正、补漏和删除均更新图谱；数据和成功状态原子提交，失败整批回滚。
- 同源同步请求合并，各来源独立推进，故障退避重试。
- 编辑时保留输入；断线保留快照，恢复后自动更新。
- 监测日志按更正后的数据复核，保留首次观察时间；遗漏与 K 线保留已应用参数。
- 保留原有功能、SQLite、系统加密配置、备份恢复与托盘后台。
- 历史统计、筛选排序和遗漏不作为下一期命中概率承诺。

## 验证

98 项自动测试通过；Windows 便携版八个页面及图谱主要流程通过。五个真实来源各核对 1000 条记录，共 5000 条，期号、号码、时间、总量与原平台一致。测试使用独立目录，未使用真实付费 AI 密钥。

## 升级

附件提供 Windows x64 便携版、安装版、SHA256SUMS.txt 和 release-manifest.json。

从旧版系统托盘选择“退出并停止后台”后再启动新版，默认沿用原数据库和配置。可先在“数据”菜单备份。上游不可用时提示延迟并保留已有数据。

11选5、大乐透和足球仍为本地导入来源。本版本没有应用内自动安装更新。
